Each directory under `clusters/` describes one k3s cluster. The flake turns it
into a NixOS system for every node, plus a command that installs, deploys and
operates them. Nodes talk over a WireGuard mesh, Cilium runs the pod network
and load balancing in eBPF (pods see real client IPs), and Longhorn replicates
volumes. If it isn't in `cluster.nix`, it isn't on the machine.

## Quick start

Run from the repository root with your admin key in `ssh-agent`
(`ssh-add ~/.ssh/k3s-admin`). Each cluster has its own command; these use
`home`.

```bash
nix run .#home -- status                 # nodes, and whether every chart installed
nix run .#home -- switch master2         # rebuild one node (or several, or `all`)
nix run .#home -- rollback master2       # previous generation
nix run .#home -- ssh master1            # shell, or append a command
nix run .#home -- kubeconfig             # ~/.kube/home.yaml + the SSH tunnel to run
nix run .#home -- image ./app.tar.gz     # load an image on every node
```

Add a node: describe it under `nodes` in `clusters/home/cluster.nix`. Every
option a node takes, with its default where it has one:

```nix
worker1 = {
  roles = ["storage" "gpu"];      # any of "server" "storage" "gpu"; [] = plain agent
  wgIP = "10.100.0.4";            # address on the WireGuard mesh (required)
  address = "192.168.2.108/24";   # static LAN address; null = DHCP, then `endpoint` is required
  gateway = "192.168.2.1";        # default: null
  interface = "ens18";            # LAN interface (default)
  location = "default";           # same location = reach each other over the LAN (default)
  endpoint = null;                # public name/IP for SSH and peers elsewhere (default)
  sshPort = 22;                   # (default)
  platform = "vm";                # "vm" (disko) or "lxc" (existing container) (default)
  disk = "/dev/sda";              # VM system disk, erased by install
  dataDisk = "/dev/sdb";          # VM disk for /data, required with "storage"
};
```

Then:

```bash
nix run .#home -- secrets sync                    # its keys
nix run .#home -- install worker1 root@<installer-ip>
nix run .#home -- switch all                      # everyone learns the new peer
```

Remove a node:

```bash
nix run .#home -- remove worker1                  # drain, move Longhorn replicas, delete
$EDITOR clusters/home/cluster.nix                 # drop it
nix run .#home -- secrets sync
nix run .#home -- switch all
```

Rekey to a new admin SSH key while the old one still works:

```bash
ssh-keygen -t ed25519 -f ~/.ssh/k3s-admin-new
cat ~/.ssh/k3s-admin-new.pub >> clusters/home/secrets/admin.pub
nix run .#home -- secrets sync && nix run .#home -- switch all    # both keys work
ssh-add -D && ssh-add ~/.ssh/k3s-admin-new
$EDITOR clusters/home/secrets/admin.pub                           # drop the old key
AGE_IDENTITY=~/.ssh/k3s-admin-new nix run .#home -- secrets sync && nix run .#home -- switch all
mv ~/.ssh/k3s-admin-new ~/.ssh/k3s-admin && mv ~/.ssh/k3s-admin-new.pub ~/.ssh/k3s-admin.pub
```

Lost keys, leaked keys, dead servers: [docs/DISASTER-RECOVERY.md](docs/DISASTER-RECOVERY.md).

> [!WARNING]
> Workloads are closed by default: every app namespace gets a `default-deny`
> NetworkPolicy. A new app is unreachable until it ships its own policy, or
> you label its namespace `default-deny=off`.
> See [network policy](docs/CONFIGURATION.md#network-policy).
